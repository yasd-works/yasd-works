## 主な実績

- **【データ分析・ML】航空機部品の故障予測**<br>
  運航データを用いた予測モデルを計10件構築。独自の解析手法を考案・導入し、直近に担当した1モデルのF1スコアを **0.25 → 0.85** に改善。予兆検知のリードタイムも **3日 → 7日** に延伸しました。

- **【DX推進】10年以上続く前提を見直し、通知遅延を解消**<br>
  「リアルタイム分析ソフトは1フライト分しか扱えない」という運用上の前提に対し、「書き出しができるなら、読み取りも可能ではないか」と仮説を立て、PoCで検証。分析範囲を拡張し、従来のツールに起因する **約1日のアラート通知遅延** を解消しました。

- **【処理改善】データ抽出・処理を約8倍に高速化**<br>
  処理アルゴリズムの改修とマルチスレッド化により、一連の処理時間を **約8時間 → 約1時間** に短縮。分析に必要なフライトデータが揃うまでの待ち時間を減らしました。

- **【業務自動化】毎日2時間のコピー＆ペーストを自動化**<br>
  SaaSアプリとGoogle WorkspaceをAPIで連携する仕組みを構築。毎日約2時間を要していた整備データ取得・転記を自動化し、手作業でコピー＆ペーストする工程をなくしました。

- **【UX改善】数千行から入力先を探す手間を削減**<br>
  整備現場へのヒアリングから、入力先の探しにくさと不要な集計列による見づらさを把握。スプレッドシートのデータ構造を整理し、APIで連携した入力欄とフィルターを既存ポータルに実装しました。普段の画面から対象を絞り込んで記入できるようにし、探す手間を大幅に減らしました。

- **【Web開発・PM】28名の制作体制を支える開発と運営**<br>
  ライター26名を含む **28名の制作体制**でPMとフルスタック開発を兼任。Cloudflare上のサーバーレス基盤、内製CMS、外部API連携、Webツール群を構築し、運用・改善を担当しています。情報ポータルは過去の30日間の集計で **約11万PV・約1.2万MAU** を記録しました。

## 大切にしていること

**タイムパフォーマンス：人が考える時間を増やす**
作業や処理待ちにかかる時間を減らし、人が判断や工夫に使える時間を増やす。改善にかける工数と、導入後の運用負荷、得られる効果を考え、小さく試して価値を確かめます。

**ヒューマンファクターズ：人の特性を踏まえて設計する**
航空の現場と業務改善の経験をもとに、「人は迷う、見落とす、間違える」という前提で画面や手順を設計します。必要な情報を見つけやすくし、判断が必要な場面を整理する。日々の操作まで考え、現場で使い続けられる仕組みをつくります。
