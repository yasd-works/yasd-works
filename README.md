## 主な実績

- **航空機部品の故障予測**
  運航データを用いた予測モデルを計10件構築。直近に担当した1モデルでF1スコアを **0.25 → 0.85** に改善し、予兆検知のリードタイムを **3日 → 7日** に延伸しました。

- **長年の前提を検証し、通知遅延を解消**
  「分析ソフトは1フライト分しか扱えない」という10年以上続いた前提を、ファイルの入出力に着目したPoCで検証。分析範囲を拡張し、従来のツールに起因する **約1日のアラート通知遅延** を解消しました。

- **データ抽出・処理の高速化**
  処理アルゴリズムの改修とマルチスレッド化により、一連の処理時間を **約8時間 → 約1時間** に短縮しました。

- **毎日2時間の転記作業を自動化**
  SaaSアプリとGoogle WorkspaceをAPIで連携し、データ取得からスプレッドシートへの反映までを自動化しました。

- **整備現場の入力画面を改善**
  現場へのヒアリングをもとに、普段使うポータルに入力欄とフィルターを実装。数千行のスプレッドシートから該当箇所を探す手間を大幅に減らしました。

- **情報ポータルの開発・運営**
  **28名の制作体制**でPMと開発主担当を兼任。Cloudflare上の基盤、内製CMS、外部API連携、Webツール群を構築し、運用・改善を担当しています。過去の30日間の集計で **約11万PV・約1.2万MAU** を記録しました。
